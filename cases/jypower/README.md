# 苏州吉远 JIYUAN（jypower.cn）网站案例

这是一个面向功率转换控制器、功率器件和电源方案的 B2B 电子元件官网复盘样本。案例页把吉远首页的蓝色工程语境、六个产品家族、四个应用入口、设计支持行动和新闻时间线重新组织成一条“从器件到电源设计”的路径，供后续网站和 AI 上下文复用。

## 来源与观察边界

- 原站：[https://www.jypower.cn/](https://www.jypower.cn/)。本次观察日期为 2026-08-23（Asia/Shanghai）。
- 英文入口：[https://en.jypower.cn/](https://en.jypower.cn/)。本案例按中文根域首页记录，没有把英文站当作已完整归档的双语系统。
- 取样范围：公开首页 DOM、首页引用的 CSS/JS、公开图片/SVG/字体、Hero MP4，以及桌面和移动浏览器截图；没有登录、后台、真实订阅提交、接口数据或第三方数据核验。
- `assets/source/home.html` 是公开首页本地快照。为便于内部研究，已移除页脚 CNZZ 注入并保留清理注释；其他源代码和历史脚本按原样归档，不代表推荐实现。
- 根页面 viewport 含 `maximum-scale=1.0, user-scalable=no`。案例页故意不复制这一限制，并保留键盘焦点、触控反馈和 `prefers-reduced-motion` 退路。

## 已核实的页面事实

### 信息架构

1. 顶部主导航为首页、产品、应用、设计、支持、关于吉远、联系方式，并提供搜索、中文/英文切换。产品下分 AC/DC 功率转换控制器、USB PD or Type C、功率器件、同步整流控制器、霍尔与 DC-DC 控制器、参考电压/运放/光耦六组；应用下分 AC/DC 电源、USB PD & Type C、LED 驱动电源、电机驱动四组。
2. Hero 观察到 4 张内容：专业功率转换器件供应商、加速创新/降本增效、吉远科技/科技节源、连接客户/分享方案。Swiper 3.4.2、Swiper Animate 和分页指示组成首屏切换；第四张叠加一个自动播放、静音循环的 MP4。
3. Hero 下方直接放六张产品家族卡片，每张卡有图片、名称、结果导向短句和详情路由。产品内容不是只展示型号，而是先按工程师的功能任务做分组。
4. 应用区用四张图片卡把元件放回 AC/DC 电源、快充、LED、电机驱动等设备结果；产品路径和应用路径并行，给工程师和采购者两种进入方式。
5. 最新资讯区观察到 2026-03-03、2026-01-12、2025-12-25、2025-11-24 四条日期列表。资讯不抢占产品主叙事，但给品牌增加持续更新的时间信号。
6. 资讯之后是订购、设计、支持、加入四个行动卡：样品/购买、设计课堂、技术支持、人才加入。页脚公开了苏州和深圳两个联系地点、电话、传真、邮箱，并保留微信二维码入口。

## 可迁移经验

### 1. 用工程语境先解释技术

电路图、器件样板、蓝色波形和电源设备让控制器先拥有工作尺度，再由产品名和参数补足理解。专业视觉可以有氛围，但背景必须服务于“这是什么工程”。

### 2. 产品路径与应用路径并行

“AC/DC、USB PD、功率器件……”适合已经知道要找什么的工程师；“AC/DC 电源、LED、电机……”适合按产品结果找方案的采购者。两条路径最终要汇入同一详情、选型或样品动作。

### 3. 每个分类先给一句结果导向说明

卡片不需要一开始展示完整料号表。先用“适配多场景电源需求”“高功率充电完整解决方案”等短句减少选择成本，再把拓扑、封装、电气参数和合规信息放进二级页面。

### 4. 把设计和样品当作产品的一部分

对于芯片和器件，购买前的参考设计、应用课堂、样品申请、测试仪器和工程师回复就是产品体验。支持入口应紧贴产品，而不是只在页脚写一句“联系我们”。

### 5. 用日期建立“仍在工作”的信号

新闻列表的价值不只是传播事件，而是让长期访问者看到品牌有持续更新的轨道。日期、标题和真实详情链接比无限滚动或夸张的“行业领先”更可信。

### 6. 承诺数字必须带口径

“20 年电源方案经验”“三代半导体功率器件”“24 小时内回复”可以作为首页自述，但正式项目必须说明起算日期、产品范围、工作时段、渠道和验证来源。

### 7. 动效增强路径，不锁住内容

Swiper、Hero 视频、GSAP、hover 和移动菜单可以建立节奏，但静态图片、真实链接、键盘焦点、视频 poster、暂停机制和 reduced-motion 退路必须独立成立。

## 不要照搬

- 不要复制 `user-scalable=no` 或 `maximum-scale=1.0`，应保留移动端缩放能力。
- 不要把没有性能预算的 jQuery、旧版 Swiper、WOW、Layer、GSAP、SplitType、SuperSlide、Layui 全部叠加进新站；选择可维护的交互层并按需加载。
- 不要让视频成为技术解释的唯一方式。提供 poster、暂停/静音、加载失败状态和文字替代；本案例归档 MP4 仅供内部研究。
- 不要使用 `javascript:;` 作为联系方式或导航占位，也不要让订阅表单只有一个按钮而缺少真实成功、失败和隐私状态。
- 不要将“20 年 / 3 代 / 24h / 苏州深圳双据点”、电话、邮箱、地址或型号指标当作其他企业的默认事实；上线前重新核验。
- 归档 Logo、产品图、字体、视频、CSS、JS 和二维码未授予生产使用权。生产项目应取得授权或重新制作。
