# 江苏吉星 KomShine（jxgtx.com）网站案例

这是一个面向光纤熔接、OTDR、测量仪器、ODN 网络和光纤工具的 B2B 工业官网复盘样本。案例页把原站的设备 Hero、六类产品任务、服务支持入口、推荐型号和全球交付数字重新组织成一条可供 AI 学习的“从现场到交付”路径。

## 来源与观察边界

- 原站：[https://www.jxgtx.com/](https://www.jxgtx.com/)。本次观察日期为 2026-08-23（Asia/Shanghai）。
- 取样范围：公开中文首页 DOM、首页引用的 CSS/JS、公开图片与字体引用，以及桌面/移动浏览器截图；没有登录、后台、真实表单提交、接口数据或第三方数据核验。
- `assets/source/home.html` 是公开首页的本地快照。为便于内部离线研究，已移除重复的 Baidu 统计加载器和 CNZZ 注入脚本并保留清理注释；其余公开脚本不代表推荐实现。
- 根页面 HTML 的 `lang` 为 `en`，但可见内容主要是中文；语言入口指向 `www.komshine.com` 的 English、Spain、Russian、Portugal、French、Arab 变体。本案例按可见中文首页记录，不把这些变体当作已完整归档的多语站。
- 首页公开联系方式为 `138-1489-7945`、`info@komshine.com`、`江苏省南京市雨花台区宁双路18号沁恒科技园D幢`；案例页明确标成“公开首页观察值”，不是新项目默认联系方式。

## 已核实的页面事实

### 信息架构

1. 顶部导航围绕首页、产品&解决方案、新闻资讯、服务&支持、关于吉星、联系吉星展开，并提供搜索、语言和咨询动作。产品一级入口分成光纤熔接机、OTDR、测量仪器、ODN 网络、光纤清洁、光纤工具六类。
2. Hero 观察到 5 张 `1920×750` 图片：干线光纤测试仪器、QX43 OTDR、FX39 干线熔接机、EX39 FTTx、快速连接器。源站通过 Swiper loop、4 秒 autoplay、可点击分页和 Swiper Animate 形成首屏节奏。
3. Hero 之后紧跟四个服务快捷入口：产品手册、快速指南、视频教程、售后服务。它们把产品选择延伸到安装、学习和维修。
4. 产品/解决方案区为每类任务提供一段场景解释，再进入型号或详情页。推荐产品区观察到 20 个型号入口；本案例只保留 6 个代表卡，避免把首页复刻成库存表。
5. 关于吉星区公开描述公司 2015 年 4 月成立于南京，承担光纤测量、熔接、清洁相关产品的研发、生产与销售。页面同时自述“30+ 研发团队、10+ 国际语种、50+ 服务国家、1000K+ 服务客户”，均未做第三方核验。
6. 新闻/展会入口与公司能力并列：当前公开快照可见 2025 展会条目及 2026-06-04、2026-01-16 等新闻卡；不要据此推断完整历史、更新频率或内容质量。

### 运行与响应式

- 源站使用 jQuery 3.7、Swiper 3.4.2、Swiper Animate、Bootstrap、WOW、Fancybox、Waypoints、CountUp、social-share、Layer、`index.js` 和 `common.js` 等历史前端栈。
- `main.css` 采用 `--header_h: 6.875rem`、`--container: 14.8125rem`、橙色 `#F50`、绿色 `#99cc33` 与深灰文字体系；Hero 图片使用 `object-fit: cover`，卡片普遍通过 hover 位移、阴影和颜色反馈建立层次。
- 原站在约 990px 以下切换移动 Header/汉堡菜单，服务与推荐卡进入更窄的网格或滑动布局。案例页以 1440px、390px 原站截图作为证据，并额外测试 1180/900/768/640/390 宽度。
- `common.js` 含禁用右键、复制、选择和 Ctrl+C 的 anti-copy 逻辑。本案例保留它作为研究证据，同时在“需要重构”中明确不应搬入生产项目。

## 可迁移经验

### 1. 让设备先回到真实工位

机房、施工、测试、清洁动作先建立设备尺度，再用型号、指标和详情页补足决策证据。工业产品不必一上来就堆参数；先回答“它在哪里工作”。

### 2. 用现场任务组织一级产品导航

“熔接、测试、测量、分配、清洁、工具”比一面 SKU 墙更适合采购者自我定位。每一类先讲任务与结果，详情页再承接规格、应用、合规和询盘。

### 3. 把服务当成产品的第二层

手册、快速指南、视频和售后不是页脚补充，而是设备完成安装、学习、校准和维修的交付路径。服务入口应紧跟产品首屏，而不是藏在一个泛化的下载中心里。

### 4. 推荐型号用来示范任务

推荐产品区的价值是展示“某类任务对应什么型号”，不是一次性列出所有库存。卡片只需要名称、型号、应用标签和真实详情路由，筛选/搜索再承担完整目录。

### 5. 用时间、覆盖、影响表达企业证据

研发团队、国际语种、服务国家、服务客户分别对应能力、沟通、网络和影响面。每个数字都必须带统计日期、单位、口径、来源与验证状态；自述数字不能自动升级成事实。

### 6. 动效增强路径，不锁住内容

轮播、hover、CountUp、菜单和新闻中心放大可以建立节奏，但静态标题、真实链接、图片替代文本、键盘焦点和 reduced-motion 退路必须独立成立。生产项目不应为了复刻视觉而叠加整套旧库。

## 不要照搬

- 不要把 `common.js` 的禁止复制、右键和选择逻辑带进新站；它会损害可访问性、辅助技术和用户信任。
- 不要用 `javascript:;` 作为导航占位；每个菜单项要么是真链接，要么明确提供禁用状态和下一步。
- 不要无审查地叠加 jQuery、旧版 Swiper、WOW、Layer、CountUp 等多套运行时；选择单一可维护交互层，按需加载并保留静态退路。
- 不要将“30+ / 10+ / 50+ / 1000K+”、电话、邮箱、地址或产品指标当作其他企业的默认事实；上线前重新核验所有口径和有效性。
- 不要直接使用归档的 Logo、照片、字体、CSS、JS 或产品图。它们仅供内部研究、设计复盘和 AI 上下文；生产项目需取得授权或重新制作。
- 本次首页观察未发现需要归档的独立视频文件；不要把“有视频教程”理解成已完成视频资产交付，应先核对页面真实内容、版权和加载策略。

## 如何使用

- 直接打开 [index.html](index.html) 查看视觉化复盘页。
- 用脚本或模型读取 [case.json](case.json) 获取结构化事实、规则和资产索引。
- 查看 [assets/source/manifest.md](assets/source/manifest.md) 了解源文件、别名映射、清理记录和截图尺寸。
- 本地预览：在仓库根目录运行 `python3 -m http.server 4173 --bind 127.0.0.1`，访问 `http://127.0.0.1:4173/cases/jxgtx/`。
