# 能翊行（enerax.cn）网站案例

这是一个面向新能源设备、移动能源与换电方案的 B2B 官网拆解样本。案例页把原站的视觉线索改写成可供 AI 复用的决策路径：先看设备如何工作，再按采购任务找产品，随后按工况筛选场景，最后用数据、新闻和伙伴证明持续交付能力。

## 来源与观察边界

- 原站：[https://www.enerax.cn/](https://www.enerax.cn/)（用户提供的 `https://enerax.cn/` 在本次观察中重定向/访问策略不稳定，研究快照使用同一站点的 `www` 主机名）。
- 观察日期：2026-08-23（Asia/Shanghai）。
- 取样范围：公开首页、首页引用的 CSS/JS、公开图片和桌面/移动浏览器截图；没有登录、后台、真实表单提交、接口数据或第三方数据核验。
- 原站根路径的直接命令行请求在本次观察中受到协议/WAF 限制；带查询参数的只读 URL 仅用于取得页面快照，查询参数不是原站内容的一部分。
- `assets/source/home.html` 是研究快照。为避免在本地归档继续加载第三方统计，已移除 Baidu `_hmt` 与 CNZZ 统计加载器，并保留清理注释；原站公开脚本的其余内容不代表推荐实现。

## 已核实的页面事实

### 信息架构

1. 顶部导航将内容拆成产品中心、行业应用、服务中心、新闻&展会、关于我们和联系我们，并提供中英文切换与搜索入口。
2. 产品中心按三层组织：移动电源、补能装置、数字能源管理平台。其下继续展开便携式应急电源、储能系统柜、移动充储车、移动充电/换电车、商用车换电站和运营平台等系列/单品。
3. 行业应用公开 8 个入口：出租车/网约车、城市配送、专业服务运输、矿山矿产运输、城市渣土、港口短驳、钢厂短驳、公水联运。案例页展示其中 6 个有代表性的场景卡片，完整入口仍可从原站复核。
4. 首页后半段依次出现品牌使命、企业能力数字、新闻与伙伴/生态内容，形成“方案—证据—下一步”的尾部路径。

### 交互与动效

- 首页 Hero 使用 Swiper 循环轮播；源码中配置 `speed: 1000`、`autoplay.delay: 7000`、`disableOnInteraction: false`，首屏同时存在视频与静态图片层。
- 产品、应用、新闻和伙伴区域采用多组 Swiper/横向滚动模块；主脚本还包含 sticky 导航、tab、返回顶部、表单校验、计数器和移动端菜单。
- `more.js` 使用 GSAP、ScrollTrigger 和 SplitType 做 hover、文字拆分与滚动触发；`main.js` 额外初始化了两次 WOW，属于应在新项目中审慎清理的历史堆栈。
- 主样式以 `0.8333333333vw` 为桌面根字号，在 1024–1366、767–1024 和 767 以下分段调整，并用 `--color-zt: #0ACB74` 作为绿色动作色。该“视口尺度 + 断点兜底”是可观察事实，不等于唯一推荐方案。
- 原站 `antiClone` 会阻止 Ctrl+C、复制、选取、右键及图片拖拽；这份案例页明确不复制该行为。

### 原站自述数字（未做第三方核验）

首页公开出现：`6+` 全球布局、`50+` 客户群覆盖国家&地区、`40%+` 研发人员占比、`100+` 有效专利、`900+` 累计交付。它们在本案例中只作为“数字证明条”的内容结构示例；生产项目必须补充统计口径、截止日期、来源和核验状态。

## 可迁移经验

### 1. 用场景 Hero 解释工业产品为何重要

当产品价值依赖设备如何运行，首屏先展示车辆、站点、柜体、电池或调度动作，再给一句短使命和一个明确动作。设备视频应始终有 poster、静音、暂停控制、加载失败静态退路和文字替代。

### 2. 用决策任务做产品目录

硬件、补能站端和软件平台通常对应不同采购角色与决策速度。先分层，再在每层内使用系列入口、代表单品和详情页承接规格，避免把首页变成 SKU 墙。

### 3. 把行业应用做成筛选器

场景卡片应写清高频、重载、固定路线、短停靠、连续作业等运营约束，并把卡片连到相应的方案或产品。行业名只是标签，工况才是匹配依据。

### 4. 用“使命句 + 证据条”收束首页

一句可记忆的主张可以留下品牌感，统计、专利、交付、新闻和伙伴内容负责给出继续核验的线索。数字不能脱离来源、日期、口径单独使用。

### 5. 动效是增强层，不是阅读前提

Swiper、GSAP、WOW 和文字拆分可以制造节奏，但同一内容必须在无脚本、键盘、触摸、慢网和 `prefers-reduced-motion` 下仍然可读、可选、可进入。案例页用轻量 CSS + 原生 JS 重做了这组交互。

## 不要照搬

- 不要使用 `user-scalable=no`，要保留移动端缩放能力。
- 不要用 `antiClone` 禁止复制、右键或选择；研究保护不能以牺牲可访问性和用户控制为代价。
- 不要在没有预算和加载策略时叠加 jQuery、旧版 Swiper、WOW、GSAP、ScrollTrigger、Layer 等多套运行时。
- 不要让视频自动播放成为唯一信息来源；提供暂停、静态 poster、字幕/文字替代和失败状态。
- 不要把 `javascript:;` 作为咨询/询盘入口；使用真实按钮、表单、电话/邮件链接或明确的预约流程。
- 不要把 Enerax 的企业数字、联系方式、专利或交付量当作新客户的默认事实；复制结构，重新核验内容。
- 归档图片、Logo、CSS 与 JS 仅供内部研究与 AI 上下文，未授予生产项目使用权。要上线相似视觉，应取得授权或重新制作。

## 如何使用

- 直接打开 [index.html](index.html) 查看视觉化复盘页。
- 用脚本或模型读取 [case.json](case.json) 获取结构化事实、规则和资产索引。
- 查看 [assets/source/manifest.md](assets/source/manifest.md) 了解每个归档文件的来源和清理情况。
- 本地预览：在仓库根目录运行 `python3 -m http.server 4173 --bind 127.0.0.1`，再访问 `http://127.0.0.1:4173/cases/enerax/`。
