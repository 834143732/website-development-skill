# 卓越光华智能制造企业站参考拆解

## 审阅范围

- 参考站点：[苏州卓越光华信息技术有限公司](http://www.szzygh.cn/)
- 审阅日期：2026-08-20
- 实际检查页面：[首页](http://www.szzygh.cn/)、[MES 系统列表](http://www.szzygh.cn/MES.html)、[注塑行业 MES 系统详情](http://www.szzygh.cn/MES/33.html)
- 实际检查视口：桌面端 1440x900、移动端 390x844
- 分类标签：智能制造、MES/WMS/DCS、工业软件与配套硬件、B2B 企业站、深蓝科技、分屏叙事、中高内容密度
- 未验证项：审阅时首页、列表和详情媒体均能加载，但未取得独立控制台日志；运行时错误仍需在实际项目验收中重新检查。
- 本文将页面可见内容视为参考站点自述，不验证成立年份、研发年限、合作伙伴数量、专利软著或新闻事实。

## 核心判断

该站最值得借鉴的是把“软件方案”和“配套硬件”作为两条并行入口，再用公司介绍、数字背书、行业方案和新闻补足采购信任。它适合既提供 MES/WMS 等咨询实施，又销售料架、工业平板、PDA、扫码枪和打印机的制造数字化服务商；可复用的是业务分层和证据组织，不是通用机器人背景或整屏滚动模板。

## 值得借鉴

### 首屏先完成双业务分流

- 首页轮播每一帧围绕 MES、WMS、DCS 或电子料架等一个主题，标题下直接提供“软件产品”和“硬件产品”双 CTA，访客无需先理解公司组织架构即可进入对应业务。
- 主导航只保留首页、软件产品、硬件产品、新闻、关于和联系，电话作为高频咨询信息常驻；首页内容再展开具体系统和设备类别。
- 复用时应让首屏图像展示真实软件界面、设备或产线结果，并让 CTA 落到对应列表或方案，而不是只用泛化工业素材制造科技感。

### 软件方案与硬件目录使用不同浏览方式

- 硬件区先提供电子料架、工业平板、PDA、扫码枪和打印机五类入口，再用轮播展示具体型号，适合“类别清楚、型号数量中等”的目录。
- 软件区把 MES、WMS、轻量级 WMS、DCS 和电子料架亮灯系统并列成五个方案面板，每项都能进入详情；这种结构强调业务能力，而不是强行把服务包装成 SKU。
- 同时经营软硬件时，应分别建立方案数据模型和产品数据模型，再通过适用行业、设备兼容、实施服务或案例关联，避免把两类内容混成一套卡片字段。

### 公司可信度放在业务路径之后

- 首页在产品入口之后展示公司说明和四组数字，再进入解决方案与新闻，让访客先知道“能提供什么”，随后再判断“是否可信”。
- 数字采用“数值 + 口径标签”的紧凑表达，视觉扫描效率高。复用时必须给每项数字保留来源、统计口径和更新时间，不能用动画代替可信证据。
- 新闻标题集中在 MES 与制造场景，有助于持续解释专业能力；内容应连接相关方案或行业页面，不只承担 SEO 更新频率。

### 方案详情用流程图建立工程证据

- 注塑行业 MES 详情按整体蓝图、硬件架构、设备管理、模具管理、品质管理和安灯响应顺序展示七组图解，形成从系统架构到现场流程的证据链。
- 适合流程复杂、文字难以快速解释的工业软件项目，但图解旁仍应有可搜索的标题、摘要、关键结论和适用范围。
- 列表页采用交替图文卡组织注塑、SMT 和汽车线束三个行业方案，适合先按行业任务分流，再进入详细流程。

### 桌面沉浸叙事与移动自然流分开处理

- 桌面首页使用整屏区块、固定导航和右侧楼层指示，让公司、方案、新闻等长首页仍有明显段落节奏。
- 390x844 下页面改为自然纵向滚动，文档宽度未超过视口；导航收敛为汉堡菜单，硬件、方案和新闻转为移动卡片。
- 复用整屏滚动时，应在移动端主动解除固定整屏高度和滚动劫持，不把桌面页面整体缩小。

## 适用条件

- 客户同时提供工业软件实施与配套硬件销售，且两类业务都需要独立询盘入口。
- 软件能力能按系统或行业形成 3-6 个稳定方案，硬件能按清晰类别和型号维护。
- 客户能提供真实软件界面、设备照片、架构图、流程图、实施范围或案例证据中的至少两类资产。
- 站点主要目标是说明能力、建立信任和获取咨询，而不是支持上百型号的复杂参数筛选或在线交易。

## 不应照搬

- **泛化首屏素材：** 首页多张轮播使用常见机器人、数据大屏和工业场景图，能建立行业氛围，却不能直接证明软件效果。客户有真实后台、现场或设备资产时应优先使用真实内容。
- **可见标题语义不足：** 首页 Hero 和主要模块标题大多不是 `h1`-`h3`；移动端查询到的语义标题主要是数字与页脚品牌。页面应有唯一 H1 和连续章节标题，不能以视觉字号代替文档结构。
- **移动菜单控件无语义：** 390px 下菜单触发器为 `.m-bm-navbtn` 普通 `div`，没有 `role`、`tabindex`、`aria-label` 或 `aria-expanded`；应改为原生 `button`，支持键盘、焦点恢复和 Esc 关闭。
- **图片替代文本不完整：** 首页 47 个 `img` 中有 17 个空 `alt`。装饰图可保留空值，产品、方案、二维码和信息图必须提供与用途一致的替代文本。
- **信息图承载全部正文：** 注塑 MES 详情的主要内容集中在七张图片中，替代文本仅为 `1.jpg` 至 `7.jpg`。架构与流程图必须补充文本摘要、关键节点、放大/下载入口和有效替代说明。
- **内容与数据一致性：** 公司数字采用滚动计数，截图过程中显示中间值；脚本失败、快速滚动或减少动效时必须直接显示最终值，且最终值与正文、后台数据一致。
- **轮播克隆增加重复内容：** 首页硬件和新闻轮播在 DOM 中出现多组重复链接。复制节点必须对辅助技术和 Tab 顺序隐藏，并控制首屏之外的资源加载。

## 复用时的最小验收

- 从首屏的“软件产品”和“硬件产品”分别到达正确列表；软件方案、硬件类别、型号、行业详情和咨询入口之间有可返回的面包屑或导航路径。
- 方案列表与详情读取统一数据；详情至少包含业务问题、实施范围、流程/架构证据、适用行业和咨询 CTA，不只是一组图片。
- 公司数字均有数据来源、统计口径和更新时间；关闭 JS、快速滚动及 `prefers-reduced-motion: reduce` 时仍显示最终值。
- 1440px 下整屏区块、楼层导航和浮动咨询入口不遮挡正文；390px 下改为自然滚动，`scrollWidth <= clientWidth`，菜单、轮播、卡片和底部入口均可触控。
- 用键盘验证菜单、二级栏目、轮播、卡片和浮动入口；菜单按钮具有可访问名称、`aria-expanded`、可见焦点、Esc 关闭与焦点恢复。
- 检查产品图、方案图、二维码、轮播克隆、懒加载、控制台和失败媒体；信息图同时提供文本摘要或可访问的详细说明。
