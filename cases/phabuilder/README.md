# 微构工场（phabuilder.com）网站案例

## 案例定位

这是一个面向 PHA 生物材料、合成生物学和可持续制造客户的官网复盘。案例重点不是复制绿色滤镜，而是提炼原站如何把科研能力、材料应用、产业化和终端生活组织成一条完整说服路径。

- 原站：<https://www.phabuilder.com/>
- 站点名称：微构工场（页面标题为“微小改变世界 构建绿色未来 - 微构工场”）
- 页面类型：生物材料 / 合成生物学 / 工业生物制造官网
- 观察时间：2026-08-23（Asia/Shanghai）
- 观察方式：公开首页的浏览器只读加载、响应 DOM、CSS/JS、图片资源与桌面/手机截图；未提交表单、未登录、未改变站点状态。原站直接使用命令行 GET 时返回 403，本案例的 `home.html` 通过浏览器同源只读请求获取，并移除了 51.la、CNZZ 的站点分析脚本及 ID。
- 案例页：打开同目录的 `index.html`。

## 已核实事实

1. 顶部导航包含首页、PHAmily 原料产品、PHAbrary 定制方案、PHAdustry 智造产线、PHA Life 多元创造、其他非 PHA 产品、关于我们，以及中英文入口、搜索和 PHA 采购入口。PHAmily、PHAbrary、PHAdustry 和关于我们有二级导航。
2. 桌面端首页使用 `fullPage.js`，源码中有 9 个全屏章节与右侧进度导航：Hero、关于我们、视频、核心产品、4P 产业战略、生物制造体系、热销产品、公司新闻和页脚/联系。`fullPage` 仅在窗口宽度大于 990px 时初始化，990px 及以下会销毁实例。
3. Hero 使用自然湖泊场景图，叠加“微小改变世界 构建绿色未来”和“为您提供低碳、自然友好的 PHA 生物材料！”等主张。横向 Swiper 配置为循环、5 秒自动播放、1 秒切换和淡入效果；当前首页源码中的两个文本状态引用了同一张湖泊图片。
4. 关于区把清华大学成果转化、专家发起、PHA 研发和 4P 战略放在同一屏，右侧使用产业合作伙伴 Logo 错落墙；手机端改用一张 PHA 示意 SVG。
5. 核心产品区用“PHA，大自然的慷慨馈赠”作为标题，介绍 PHA（聚羟基脂肪酸酯）的低碳、亲和与自然降解属性，并用圆形生物制造/应用示意图与底部认证图集承接可信度。
6. 4P 产业战略对应四层品牌语言：PHAmily（浩瀚 PHA 库）、PHAbrary（产品解决方案）、PHAdustry（全球产业化 + 工业 4.0）、PHA Life（产品商业化）。四个入口共享 PHA 词根，但分别对应材料组合、应用开发、产业化和终端生活。
7. 生物制造区以“简易、节能低碳、高效、非粮”四张卡片表达工厂优势，页面文案涉及设备成本、能耗、产率、生产时间和非粮碳源等数字或承诺；这些均是原站自述，本案例没有第三方核验。
8. 热销产品区展示 3 个产品卡片：PB3000G（P(3HB)，3HB mol% 100%）、PB3430G（P(3HB-co-4HB)，4HB mol% 15±1）和 PV3000G（P(3HB-co-3HV)，3HV mol% 3±1），并配置 Swiper 与详情链接。
9. 公司新闻区使用 10 条左右的循环 Swiper，覆盖 PHA 大会、工信部标志性产品、绿色低碳技术创新、ESG、科研成果与合作事件；新闻卡片包含标题、日期、图片和详情入口。
10. 原站加载 jQuery 3.3.1、Swiper 3.4.2、WOW、fullPage.js、ScrollOverflow、Fancybox、CountUp 和第三方分享/统计脚本。页面根 HTML 的 `lang` 当前为 `en`，尽管主体内容为中文。
11. 桌面端有右侧章节进度、邮件/联系浮层和返回顶部入口；移动端隐藏桌面导航、关闭 fullPage，并显示汉堡菜单。浏览器在 390px 模拟下能看到菜单按钮和自然滚动，但首屏标题需要逐元素检查才能避免裁切。

## 可迁移经验（条件规则）

### 1. 用自然场景先建立绿色使命，再谈材料

当产品的价值是低碳、自然友好或循环利用，真实自然场景能先给访客方向感。Hero 只保留场景、使命、简短副标题和一个动作；技术定义、认证、数字和适用条件放到后续 HTML 内容中。

### 2. 用统一词根表达多层业务

当研发、应用、制造和商业化共享同一个底层技术时，可以设计一组统一词根的业务家族。每个词必须同时拥有用户能理解的副标题、对应详情页和一条可核验证据，避免成为只对内部人员有意义的品牌造词。

### 3. 用“解释顺序”降低技术网站的认知负荷

推荐顺序是：自然愿景 → 公司来源 → 技术/材料解释 → 产业战略 → 制造优势 → 产品型号 → 新闻与联系。复杂产品不应一上来就丢规格表，也不能只用情绪图替代技术事实。

### 4. 一张优势卡只承担一个判断

“简易、节能低碳、高效、非粮”四张卡是很好的压缩方式。每张卡保留一个标题、两句说明和一条证据链接；成本、能耗、产率、时间等指标必须附基线、样本、日期和验证方。

### 5. 产品区是品牌叙事到采购行动的桥

当官网最终需要承接 B2B 采购时，产品卡应把材料名称、共聚比例、图片、型号和详情链接放在同一个可点击区域。hover 只负责预览；点击、焦点、触摸和键盘都必须能完成切换。

### 6. 新闻区要证明“品牌正在发生”

对于技术和材料企业，新闻不是填充，而是第三方活动、认证、ESG、科研与合作的时间线。保留真实日期、原文链接和来源；没有详情页的内容应标成待补，而不是用占位新闻制造活跃感。

### 7. 全屏叙事要有自然滚动的退路

桌面端可以使用 `scroll-snap`、粘性章节导航或 fullPage 风格的进度指示；移动端应让内容自然延续。自动播放、视频、视差和鼠标滚轮不能成为读取信息的唯一条件，并必须尊重 `prefers-reduced-motion`。

## 不应直接复制的部分

- 根 HTML 的 `lang="en"` 与中文内容不匹配；新项目应使用正确语言标记和可切换语言入口。
- 原站桌面端依赖 fullPage.js、ScrollOverflow、Swiper 和 WOW 叠加，阅读、键盘和浏览器返回行为容易被插件状态影响；新项目应先保证自然文档流，再加章节增强。
- 原站在 390px 视觉核验中首屏标题曾出现横向裁切风险，Logo、汉堡菜单、标题和副标题要用真实设备宽度逐元素检查，不能只检查 `scrollWidth`。
- 视频章节直接自动播放并在进入章节后取消静音；生产项目要默认静音、提供 poster、暂停按钮、字幕/文字替代和低带宽策略，不能把声音突然打开作为体验的一部分。
- 原站有第三方 51.la、CNZZ、分享、Fancybox 等资源；案例归档已移除 51.la、CNZZ 的站点分析脚本及 ID。生产项目要重新评估隐私、性能、跨域和脚本供应链，不要照搬整套插件。
- 原站产品与新闻大量使用轮播，移动端必须提供可见分页、触摸/键盘操作和静态内容回退；不要用自动轮播隐藏规格或新闻。
- “1–3 年自然环境消解”“时间比例 1%”“超过 100 亿种组合”“成本降低 30%”“能耗减少 50% 以上”“产率提高 80%”等都是原站自述。AI 不得把这些数字迁移给其他客户，也不能根据行业常识补齐统计口径。
- 原站 Logo、图片、视频、CSS、JS、新闻文案和认证/伙伴标识仅作内部研究归档；没有授权时不得用于客户生产项目。

## 本案例页如何改进原模式

- 保留自然场景、4P 词根和九章任务，但把 fullPage 章节变成可操作的自然滚动时间轴。
- 用 `role="tablist"`、方向键、click、focus 和 pointer 共同驱动章节与产品切换。
- 使用 `lang="zh-CN"`、可缩放 viewport、跳过导航、可见焦点、静态文本回退和 reduced-motion。
- 把所有自述数字标成“原站自述 / 需验证口径”，不让 AI 把宣传数字误当成行业事实。
- 手机端重新编排 4P、制造优势、产品和新闻，不依赖隐藏内容来换取视觉留白。
