# 舟欧工业科技（zoe-industry.cn）网站案例

> 观察日期：2026-08-23（Asia/Shanghai）｜来源：[zoe-industry.cn](https://www.zoe-industry.cn/)

这是一个面向工业自动化产品、欧洲品牌代理/经销与跨境 MRO 采购的中文官网复盘页。案例页不是原站重制，而是把公开首页中值得喂给 AI 的信息架构、视觉线索、交互规则和事实边界提炼出来。

## 一句话结论

舟欧首页把“产品中心、品牌中心、关于我们、行业领域、新闻、联系方式”串成一条供应商判断链：访客可以按产品找零件，也可以按行业找解决方案，再用品牌关系、客户 Logo、新闻日期和联系方式完成信任确认。

## 已观察到的页面结构

- **Hero**：三张工业现场视觉，分别表达工业自动化服务商、美国机床解决方案、德国清洁系统；底层使用 Swiper/动画依赖。
- **产品中心**：编码器、工业泵、工业阀、工业电机、工件夹具、传感器、电气设备及元件、仪器仪表、机械及配件九类。
- **品牌中心**：代理品牌与经销品牌两条入口，配合 Profiroll、Carlo Gavazzi、Siemens、Lynch Motor、SMC、Festo 等可识别 Logo。
- **关于我们**：公开自述 2016 年成立，拥有德国分支，与欧洲供应商建立直接联系，服务汽车、冶金、电力、航空航天、轨道交通等行业。
- **服务领域**：矿山设备、冶金、能源、生物医药、机械加工、船舶、物流运输、轨道交通、航空航天、电力、石油化工、汽车制造十二类。
- **新闻与活动**：以日期列表承接进博会、品牌授权、贸易秘密保护等内容，建立持续更新感。
- **联系与浮层**：电话、邮箱、临港地址、微信二维码，以及右侧联系/客服/返回顶部悬浮按钮。

## 值得迁移的经验

### 1. 用“三条路径”降低 MRO 目录的选择成本

工业采购访客并不总是知道料号。一级导航同时提供“按产品家族”“按品牌关系”“按行业任务”三条入口，再让三条路径汇入详情、交期、替代和询价，是比单纯做产品瀑布流更稳的 B2B 信息架构。

### 2. 品牌墙要从装饰升级为关系字段

品牌 Logo 适合快速扫读，但生产站点应该给每个品牌卡增加 `relationship`、`region`、`updatedAt`、`evidenceUrl`、`alternativePolicy` 等字段，明确“代理、经销、OEM、可替代”不是同义词。

### 3. 行业入口必须回到工艺任务

“汽车制造”或“冶金行业”只能是筛选入口。AI 生成新站时，应继续下钻到焊装、涂装、总装、检测、备件或泵阀传感器的真实任务，并给每个任务一个可执行动作。

### 4. 信任数字必须带事实边界

官网公开首页出现“1000+ 全球供应商、2000+ 全球合作客户、50+ 国内名校团队占比”等数字。本案例保留这些来源说法，但标注为“待核验”，不将其转写成第三方事实。任何项目都应记录统计时间、口径、证据和责任人。

### 5. Hero 的真实设备画面服务于理解

工业网站不必靠抽象渐变制造科技感。设备、机械臂、清洁系统和现场图片能先建立行业语境，再用一句短文案回答“你提供什么”。若使用视频，必须提供 poster、暂停按钮、静态图片和低带宽退路。

## 设计与技术拆解

- **色彩**：原站以蓝色工业现场为主；案例页改用钢蓝 `#123b4a`、青色 `#5db9c0` 与橙色 `#ef6d3f`，保留“工程 + 交付警示”的关系，不把案例页误认成原站。
- **布局**：桌面使用大留白、非对称网格与整幅现场图；产品模块使用左侧家族选择器 + 右侧换景；品牌模块使用六格识别墙 + 关系注释。
- **交互**：Hero、产品和行业选择器支持点击、键盘方向键、Home/End；移动端导航支持 Escape 关闭；联系浮层支持焦点可见、外部点击关闭和返回顶部。
- **动效**：IntersectionObserver 用于进入视口的轻量 reveal；背景换景有短暂淡入；`prefers-reduced-motion` 下停止自动轮播、旋转和过渡。
- **响应式**：`1180 / 900 / 640px` 三个主要收窄点，产品九类在移动端变成双列按钮，行业十二类变成双列，截图审计保留原站桌面与手机视觉差异。

## 不要直接复制

1. 原站 HTML 的 `user-scalable=no` 会限制用户缩放；重构必须允许缩放。
2. `javascript:;` 空链接、没有说明下一步的浮层按钮和第三方统计加载器不应进入新项目。
3. 原始 CSS/JS 包含多套旧版 jQuery、Swiper、WOW、Layer 等依赖；只在确有需求且完成安全、性能和可访问性审计时复用。
4. 图片、Logo、字体、客户标识和品牌授权文案仅用于内部研究；生产项目要获得授权或重新制作。
5. “2016、1000+、2000+、50+”是页面公开自述/观察值，不是新企业可以默认套用的事实。
