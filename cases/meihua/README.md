# 梅花集团（meihua.group）网站案例

这是一个面向氨基酸、食品配料、动物营养与生物制造企业的官网拆解样本。案例页把梅花首页的视觉节奏改写成一条可供 AI 复用的翻译路径：先用家庭与食物建立亲和力，再用产品平台、全球品质数字和生物制造地图回答“能做什么、做得多大、下一步往哪里走”。

## 来源与观察边界

- 原站：[https://www.meihua.group/](https://www.meihua.group/)。本次观察日期为 2026-08-23（Asia/Shanghai）。
- 官方英文变体：[https://english.meihua.group/](https://english.meihua.group/)。根域抓取到的是中文首页，英文子域保留同一套首页结构的英文 DOM；两份快照都归档，便于比较双语信息架构。
- 取样范围：公开首页 DOM、首页引用的 CSS/JS/Lottie 数据、公开图片和桌面/移动浏览器截图；没有登录、后台、真实表单提交、接口数据或第三方数据核验。
- `assets/source/home.html` 是根域中文首页快照，`assets/source/home-en.html` 是英文子域首页快照。为了离线研究，已移除 WowPop、Google Analytics 与 Baidu 统计加载器，并保留清理注释；原站公开脚本的其余内容不代表推荐实现。
- 根域 HTML 的 `lang`/viewport 与视觉内容存在中英文混合迹象；在重新制作时应由内容系统明确语言、切换规则和 SEO canonical，不要依赖浏览器或脚本猜测。

## 已核实的页面事实

### 信息架构

1. 顶部导航围绕 About Us、Product、R&D、Talent、Investor Relations、Sustainability 与社会责任展开，并提供搜索、语言和社交入口。
2. 首页产品平台有 7 个平行入口：动物营养、鲜味剂/食品味觉、食品原料、胶体多糖、动物保健、植物基蛋白与其他、植物营养。桌面端以横向展开卡片呈现，移动端在 1200px 以下切换为 Slick 滑动（`slidesToShow` 在 3/2/1 之间响应）。
3. Hero 使用两张家庭与食物照片，Slick 配置为淡入（`fade: true`）、约 10 秒自动切换、无箭头、圆点指示；中文根域首屏文案强调“成为合成生物学领军企业”。移动端使用独立裁切图。
4. 品质区用三个首页自述指标建立规模感：20 年全球服务经验（Since 2005）、150 个国家/地区、服务 30 亿人口。它们分别承担时间、范围、影响面的递进。
5. 生物制造区用固定中心视觉、滚动/定位文本、Lottie JSON 和两段 WebM 视频，解释可再生植物资源、效率与可持续生产、供应链循环等能力；未来应用列出氨基酸、生物基化学品、DNA 合成、医药中间体、功能食品原料、蛋白质或多肽、其他 7 个方向。
6. 首页源码中新闻模块目前以注释块存在，未作为可见首页模块输出；这应视为当前快照事实，不应假设新闻功能已上线。

### 运行与响应式

- 公开首页引用 Yongsy、jQuery、Layer、站点公共脚本、压缩基础脚本、`common.js` 与 `lottie.min.js`；Slick、计数、sticky、WOW/Lottie 等行为由这套历史前端栈组合完成。
- 原站移动 viewport 写有 `user-scalable=no`。案例页故意不复制这一限制，并保留键盘操作、可见焦点、`prefers-reduced-motion` 和无脚本静态内容。
- 联系方式在公开页脚源码中出现：`+86 316-2359999`、`meihua@meihuagrp.com`。案例页把它们标为“观察到的公开联系方式”，不是新项目默认联系信息。

## 可迁移经验

### 1. 从结果开始，再讲原料

当技术离用户很远时，先用食物、健康、环境或日常动作建立结果感，再进入氨基酸、工艺与合成生物学。技术深度没有被删掉，而是延后到用户已经理解“为什么重要”之后。

### 2. 用产品平台替代 SKU 墙

将品类按采购任务平行展开，每类配一句结果导向的解释，详情页再承接规格、应用、合规和询盘。入口数量超过 6 个时优先使用分类、横向滑动或筛选，不要继续压缩字体。

### 3. 用“时间—范围—影响”组织证据

三类数字比单一“全球领先”更易记忆，但每个数字必须带单位、统计日期、口径、来源和验证状态。案例页中的 20/150/3 仅作结构示例。

### 4. 用“中心能力 + 应用轨道”讲研发边界

当企业既有成熟产品又有未来方向时，可让一个中心视觉承载制造能力，周围用领域标签展开探索。每个标签都应有详情、阶段状态或证据，不能只做环形装饰。

### 5. 让动效解释关系，而非替代内容

淡入轮播、产品换景、计数、固定滚动和 Lottie 可以建立阅读节奏；标题、链接、静态值和 poster 必须在慢网、键盘、触摸、无脚本与 reduced-motion 下仍然可读。

### 6. 把双语当成内容系统问题

根域中文、英文子域与导航/SEO 的关系应在项目初期确定。可以复用同一模块结构，但不要仅靠 CSS 隐藏语言、复制机器翻译或让两个域名的统计口径漂移。

## 不要照搬

- 不要使用 `user-scalable=no`，应保留移动端缩放能力。
- 不要在没有性能预算时叠加 jQuery、旧版 Slick、WOW、Layer、Lottie 和多套公共脚本；选择一个可维护的交互层并做按需加载。
- 不要让视频或 Lottie 成为唯一技术解释；提供 poster、暂停/静音、文字替代、加载失败状态和 reduced-motion 退路。
- 不要把“20 年 / 150 个国家或地区 / 30 亿人口”、页脚电话或邮箱当作其他品牌的默认事实，生产前重新核验并标注口径。
- 不要把注释掉的新闻、空链接或“Others”方向当作已交付功能；每个入口都应有真实状态和下一步。
- 归档图片、Logo、字体、CSS、JS 与视频仅供内部研究、设计复盘和 AI 上下文，未授予生产项目使用权；相似项目应取得授权或重新制作。

## 如何使用

- 直接打开 [index.html](index.html) 查看视觉化复盘页。
- 用脚本或模型读取 [case.json](case.json) 获取结构化事实、规则和资产索引。
- 查看 [assets/source/manifest.md](assets/source/manifest.md) 了解中英文快照、图片映射、清理记录和未下载的大文件。
- 本地预览：在仓库根目录运行 `python3 -m http.server 4173 --bind 127.0.0.1`，再访问 `http://127.0.0.1:4173/cases/meihua/`。
