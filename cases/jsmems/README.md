# 苏州晶溯微纳（jsmems.com）网站案例

## 案例定位

这是一个面向 MEMS、微纳加工和半导体材料客户的工业技术型官网复盘。案例页将原站的内容组织、视觉层级、交互触发和响应式取舍整理成可复用规则，供后续网站制作前作为 AI 参考。

- 原站：<https://www.jsmems.com/>
- 站点名称：苏州晶溯微纳科技有限公司
- 页面类型：工业制造 / MEMS 技术服务 / 半导体材料
- 观察时间：2026-08-23（Asia/Shanghai）
- 观察方式：主页 HTML、CSS、JS 与公开图片资源的只读抓取；未提交表单、未登录、未改变站点状态。
- 案例页：打开同目录的 `index.html`。

## 已核实事实

1. 首页顶部有 7 个一级导航：首页、MEMS 加工、测试服务、半导体材料、行业动态、关于我们、联系我们；其中 MEMS 加工、测试服务、半导体材料、关于我们包含二级入口。
2. Hero 是 3 张全屏图片的 Swiper，文字叠加在图片中央；轮播自动播放间隔为 4 秒，分页器显示编号，当前图像还有约 20 秒的缓慢缩放动画。
3. 首页依次呈现公司简介、产品与服务、核心优势、行业动态、合作/品牌图集，之后是桌面页脚、备案信息、右侧咨询与返回顶部入口。
4. 产品与服务被拆成 3 组：MEMS 加工（7 个工艺卡片）、测试服务（7 个仪器/测试入口）、半导体材料（3 个入口）。桌面端为左侧分类 + 右侧多卡片 Swiper，移动端切换为更紧凑的单列布局。
5. 视觉主色是 `#73B92B`，深色页脚为 `#2D3333`；圆角变量为 `1.25rem`。原站使用 `rem` 与多个断点控制容器、字号和卡片间距。
6. CSS 对导航、按钮、卡片图片、优势图标和新闻图片设置了 hover 反馈；JS 使用 jQuery + Swiper 初始化 Hero、产品、新闻、合作图集等轮播，并实现侧边留言弹窗、返回顶部和移动端菜单。

## 可迁移经验（条件规则）

### 1. 先用“服务地图”降低工业站点理解成本

当客户提供的是多工艺、多设备或多产品线时，先把服务拆成 2–4 个高层分类，再在分类内部用编号卡片、图片和一句解释承接。左侧分类承担“我在哪条链路”，右侧卡片承担“具体怎么做”，比把几十个入口平铺在首页更容易扫描。

### 2. Hero 的任务是定调，不是承载全部信息

当行业需要建立设备、洁净室或专业人员的可信印象时，可以使用全幅场景图 + 一句价值主张 + 编号分页。必须同时提供静态图片、文字替代和可操作的前后切换；重要参数、资质和结果不能只放在轮播图片里。

### 3. 让导航在“品牌叠加态”和“可读实体态”之间切换

当 Hero 图像足够深、Logo 对比度经过验证时，顶部导航可以初始透明叠加；进入滚动或 hover/focus 后切换为实体背景和紧凑高度。移动端应直接使用清晰实体导航，不能依赖 hover。

### 4. 复杂优势用“中心锚点 + 对称卡片”表达

当品牌需要同时表达团队、交付、响应、保密等 4–6 个承诺时，可使用中心图形/关键词作为锚点，周围卡片保持对称或镜像排布。每张卡片只保留一个主标题和一条证据描述，避免把口号写成无依据的指标。

### 5. 新闻模块采用“一主三辅”建立内容权重

当新闻既要展示行业深度又要保持更新频率时，使用一张大图/长摘要作为主内容，旁边列出 3 条紧凑条目。标题、摘要和日期都需要真实来源；不要用纯视觉卡片掩盖没有证据的宣传文案。

## 不应直接复制的部分

- 原站相同桌面图用于手机端，并配合 `object-fit: cover`，可能裁掉晶圆、人物或设备关键内容；新项目应按内容焦点提供手机版图片或使用等比缩放。
- 原站把根字号直接按 `100vw` 计算。新项目应优先采用最大内容宽度 + `clamp()` 间距/字号，避免断点处突变。
- 原站首页声明 `lang="en"` 且 viewport 含 `user-scalable=no`，中文项目不应照搬；新项目要使用正确语言标记，并保留用户缩放能力。
- 原站部分表单、社交图标和咨询入口依赖 JavaScript/第三方脚本；新项目应提供无脚本静态回退、键盘焦点、错误状态和真实联系方式，不能生成占位账号。
- 原站的 20 秒图片缩放、自动轮播和 hover 视觉反馈都应尊重 `prefers-reduced-motion`，移动端需用点击/聚焦替代 hover。
- 案例页使用的原站图片、Logo、CSS、JS 仅作内部研究归档；生产项目应取得授权、重绘或替换为客户素材。
