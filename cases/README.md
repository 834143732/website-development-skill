# 网站案例库

这里存放用于喂给 AI 的独立网站案例。每个案例包含：

- `index.html`：可直接打开的视觉化复盘页；
- `README.md`：事实、经验、边界与使用说明；
- `case.json`：便于 AI/脚本读取的结构化事实、规则和资产索引；
- `assets/source/`：从公开站点归档的原始素材、CSS、JS 与来源映射。

案例中的“已核实事实”和“可迁移经验”分开记录。原站素材仅用于内部研究、设计复盘和 AI 上下文，不应在没有授权时直接用于客户生产项目。
