# 包头市晶华金属钙业网站案例

> 观察日期：2026-08-24（Asia/Shanghai）｜来源：[cn.btjhcm.com](https://cn.btjhcm.com/)

这是一个金属钙与钙系合金生产制造官网的内部研究案例。案例页不是原站重制，而是将公开首页中的产品组织、行业应用、制造能力、知识内容和信任边界提炼成可喂给 AI 的规则。

## 一句话结论

晶华首页把“材料是什么、有哪些形态、用在哪些工业场景、为什么能稳定交付、如何联系工厂”排成一条材料采购路径。它的核心价值不是页面更炫，而是让一个陌生工业元素从产品名词变成可理解、可比较、可询价的对象。

## 已观察到的页面结构

- **Hero**：厂区航拍/视频、移动端静态图与“金属钙及钙合金产品专业生产商”定位。
- **产品中心**：金属钙、钙系合金两条家族主线；金属钙继续列钙粒、钙块、钙屑、钙丝、钙压块；合金列钙铝合金、钙镁合金、稀土钙合金。
- **行业应用**：钢铁与铸造、有色金属冶炼、石油与化学、电池四类用途，分别给出脱氧、脱硫、还原和铅钙蓄电池等简短任务解释。
- **优势/能力**：品类齐全、质量稳定、工艺环保、资质齐全四张卡。
- **制造叙事**：公开自述 2006 年成立、坐落于内蒙古包头九原工业园区，并用工厂图组承接“创新型制造工厂”。
- **新闻内容**：如何选择金属钙供应商、钙氧电池等材料知识与行业教育。
- **联系与转化**：电话、邮箱、包头地址、订阅表单、招聘 CTA 和右侧电话/联系/返回顶部浮层。

## 值得迁移的经验

### 1. 先解释材料，再解释企业

对金属、合金、化工原料等陌生材料，首页第一屏应该让访客看到真实材料和工业用途，而不是从“我们是一家……”开始。元素名、形态图和工厂环境共同建立理解基础。

### 2. 产品家族之后必须有“可采购形态”

“金属钙”不是完整的采购入口。粒、块、屑、丝、压块、纯度、粒径、尺寸、包装、检测报告和交期才是工程师能继续判断的字段。AI 生成目录时应将 `family → form → specification → evidence → inquiry` 固定成路径。

### 3. 应用卡要表达工业动作

钢铁、冶金、化工、电池只是行业名词。更有效的应用卡会说明材料扮演什么角色、在哪个工艺节点加入、需要什么指标、下一步能拿到什么资料。

### 4. 能力模块应该对应采购顾虑

“品类齐全”对应规格覆盖，“质量稳定”对应批次与检测，“工艺环保”对应环境和排放证据，“资质齐全”对应证书、有效期与出口能力。四张卡的结构可以迁移，页面数字和资质必须逐项核验。

### 5. 新闻可以承担采购教育

原站把供应商选择和钙氧电池放进新闻中心。材料网站可以用知识文章回答“怎么选、怎么验、怎么替代”，但涉及化学、工艺和研究成果时必须补充来源与技术审校。

## 设计与技术拆解

- **色彩**：原站以深蓝、白色和工业灰建立工厂语境；案例页加入冰蓝与橙色，分别表达材料洁净度和验证提醒。
- **布局**：Hero 为厂区/产品换景；产品模块使用左侧家族选择器 + 右侧材料图与形态 chips；应用模块使用主场景图 + 四个可键盘操作的行业按钮。
- **交互**：Hero、产品家族、产品形态、行业应用均支持点击与方向键/Home/End；移动导航支持 Escape；联系浮层支持点击展开、外部点击关闭与返回顶部。
- **动效**：IntersectionObserver 对标签、标题、图像和卡片做独立 reveal；换景使用短暂淡入；`prefers-reduced-motion` 下停用自动轮播与过渡。
- **响应式**：`1180 / 900 / 640px` 收窄，产品家族在手机上变成双列，应用与能力卡单列，原站桌面/移动截图放入审计模块。

## 不要直接复制

1. 原站声明 `user-scalable=no`，重构必须允许用户缩放。
2. Hero 视频需要 poster、暂停、静态图片和低带宽退路，不能把 autoplay 当作唯一信息通道。
3. `javascript:;` 空链接、第三方统计加载器、订阅表单的真实提交状态不能直接带入新项目。
4. “降低 4–7 倍单位碳排放量”“直营远销 10+ 国家”“行业领先”等是官网公开自述或宣传表达，不能当作第三方结论。
5. 图片、Logo、视频、字体、客户/供应商文案仅供内部研究；生产项目需重新制作或取得授权。
