# 网站案例素材库设计

## 背景

优秀网站案例库已经收录 7 个站点，并将继续加入 Phabuilder。现有档案能够记录结构、风格、适用条件和风险，但仓库只有一个测试二维码资产，缺少可直接用于后续客户网站的通用图标、CSS、JavaScript 和图片素材。

素材库需要提高复用效率，同时避免复制参考站的品牌素材、受版权保护的图片、私有源码或整套视觉风格。

## 目标

- 遍历现有 7 个案例站和 Phabuilder，共 8 个站点，记录值得转化的素材与模式。
- 新增集中式通用素材库，按图标、CSS、JavaScript 和图片分类。
- 只保存许可证明确的开源素材、公共领域素材、CC0 素材或自行创作的文件。
- 对第三方品牌素材和源码只记录观察、来源和替代实现建议，不下载到仓库。
- 让后续网站任务可以按行业、组件、风格和用途检索素材，并在复制前确认许可与适用条件。

## 非目标

- 不镜像参考站的 Logo、产品图、项目照片、字体、整份 CSS、整份 JavaScript 或打包产物。
- 不把素材库变成完整前端框架、组件库或第三方包缓存。
- 不自动把某个案例站的颜色、动效参数或布局升级为所有项目默认。
- 不替代 npm、Composer 等依赖管理工具；成熟开源库优先记录官方包和用法，而非复制压缩文件。

## 方案

采用“集中素材库 + 各站素材观察记录”。

### 集中素材库

目录结构：

```text
assets/library/
|-- manifest.json
|-- icons/
|-- css/
|-- js/
`-- images/
```

- `icons/`：许可明确、经过清理的通用 SVG；统一 `viewBox`，颜色优先使用 `currentColor`，不得保留品牌名称或远程引用。
- `css/`：根据案例观察自行编写的独立样式模式；必须支持响应式、键盘焦点和 `prefers-reduced-motion`，不得复制参考站源码。
- `js/`：自行编写的渐进增强交互；核心内容在脚本失败时仍可用，不保存第三方库的压缩副本。
- `images/`：公共领域、CC0、许可明确或自行生成的通用图片、纹理与占位素材；不保存客户、产品、建筑项目或人物肖像等品牌专属资产。

### 素材清单

`manifest.json` 为每个落盘文件记录：

- 稳定 ID、类别、相对路径和用途标签；
- 来源 URL、来源类型和原始作者；
- 许可证名称、许可证 URL 和署名要求；
- 是否修改、修改说明、允许用途；
- SHA-256、文件大小和维护备注。

自行编写或生成的文件使用 `self-authored` 来源类型，并记录为仓库自有通用素材。第三方文件没有明确许可证时不得进入清单或资产目录。

### 参考目录

新增 `references/asset-library.md`，说明检索方式、许可边界、使用流程和素材索引。案例站观察到但不能直接保存的素材，以模式、实现建议和替代来源记录在这里或对应单站档案中。

每个案例档案增加“素材观察与归档”章节，至少记录：

- 素材或模式类型；
- 值得借鉴的用途；
- 是否允许直接保存；
- 仓库对应文件或替代实现；
- 许可与品牌风险。

### 自动校验

新增 PowerShell 校验脚本，检查：

- 清单 JSON 可解析且 ID、路径唯一；
- 每个清单文件真实存在，资产目录没有未登记文件；
- 来源、许可证和 SHA-256 完整，哈希与文件一致；
- 文件扩展名与类别匹配，SVG 不含脚本、外部引用或品牌域名；
- CSS/JS 不包含参考站域名或压缩库副本；
- 单文件体积超过约定上限时必须显式说明。

## 站点遍历流程

1. 读取单站既有档案，避免重复分析已经确认的结构。
2. 用浏览器重新检查当前首页和关键内页，记录视觉资产、图标语言、动效模式和依赖。
3. 将候选项分成“可直接采用的开源素材”“需要自行重写的通用模式”“只能记录的品牌资产”。
4. 仅对许可明确的来源下载或保存文件；CSS/JS 默认自行重写。
5. 更新单站档案和中央素材目录，运行清单、许可、哈希和技能验证。

## 错误处理

- 网站失效、资源跨域或页面阻止检查时，记录未验证，不通过其他来源猜测许可证。
- 许可证页面缺失、条款不清或来源无法确认时，候选项降级为观察记录，不落盘。
- 下载内容与声明类型不一致、SVG 含脚本或文件哈希变化时拒绝归档。
- 自动验证超过 3 分钟无输出时终止，记录未完成项并继续其他独立工作。

## 验收

- Phabuilder 成为第 8 个独立网站案例，索引和经验日志同步更新。
- 8 个案例档案都包含素材观察记录。
- 素材目录、中央参考和结构化清单可互相追溯。
- 每个落盘素材都有明确许可证或 `self-authored` 声明、来源、用途和正确哈希。
- 校验脚本能够识别缺失文件、未登记文件、重复路径、错误哈希和不安全 SVG。
- 主技能只增加素材库路由和许可边界，不把单站视觉模式设为通用默认。
