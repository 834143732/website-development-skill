# 网站制作经验记录

只记录跨项目有复用价值的失误、修正和用户确认过的长期要求。已升级到 `SKILL.md` 的规则仍保留简短记录，项目专属问题不要写入这里。

## 记录格式

使用以下字段追加记录：

- 日期：`YYYY-MM-DD`
- 项目类型：WordPress / 自建 API / 第三方 API / 纯前端
- 问题：实际出现的错误或遗漏
- 修正：采取的处理方式
- 规则状态：已确认 / 待确认
- 默认规则：如果已升级到 `SKILL.md`，写出对应的简短规则

## 已确认经验

- 日期：2026-08-09
  - 项目类型：通用网站
  - 问题：页面动效、卡片交互和部署约定需要统一执行。
  - 修正：建立网站制作默认规范 Skill，并纳入逐元素动效、滚动停顿、卡片小手指针、联系方式浮层、返回顶部和 Actions 部署要求。
  - 规则状态：已确认
  - 默认规则：所有网站任务开始前加载 `website-production-standards`。

- 日期：2026-08-09
  - 项目类型：通用网站
  - 问题：页面文字、段落和模块之间的垂直间距过大，造成大面积空白，类似参考截图中的效果。
  - 修正：收紧行高、段落间距和模块垂直留白，默认按参考截图约 50% 的间距实现。
  - 规则状态：已确认
  - 默认规则：网站默认采用紧凑、易读的行距和模块间距，避免大面积空白。

- 日期：2026-08-10
  - 项目类型：WordPress
  - 问题：容器宽度、移动端内边距和字号需要在不同视口下连续收缩，旧的固定移动端宽度容易与桌面体系脱节。
  - 修正：统一采用 1440px 最大内容宽度、`clamp(32px, 8vw, 128px)` 总内边距，以及 `clamp()` 流式字号；移动端沿用同一套容器公式，并按 1000px、900px、768px 断点收缩布局。
  - 规则状态：已确认
  - 默认规则：网站默认使用最大内容宽度 + 流式总内边距 + 流式字号的连续宽度体系。

- 日期：2026-08-10
  - 项目类型：通用网站
  - 问题：页面滚动后导航不够容易访问，导航高度也没有根据滚动状态收紧。
  - 修正：让主导航固定在顶部，并在滚动状态切换为适度紧凑的高度，同时保留可读性、触控区域和锚点偏移。
  - 规则状态：已确认
  - 默认规则：网站滚动时主导航默认固定在顶部，导航高度可适当缩小。
