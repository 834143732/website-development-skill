## 核心判断

该站最值得借鉴的是用统一的“液态微生物形状 + DNA”动效语言，把一个公众不熟悉的新质蛋白原料解释成连续的商业故事：先回答它是什么，再展示三种产品形态与多类食品应用，然后用生产闭环、ESG 影响、企业历程、认证和新闻建立信任。首页不是给每个区块加同一种淡入，而是把滚动进度分配给不同认知任务。它适合只有一个核心技术平台或原料、但存在多种产品形态和应用场景，需要同时教育食品研发客户、品牌合作方与公众的食品科技或生物制造品牌；没有可靠证据、真实应用资产和动效降级预算时不应采用如此长的固定滚动叙事。

## 值得借鉴

### 用一个动态母题统一新技术品牌

- 首页首屏使用橙绿液态粒子、半透明团块与 DNA 作为第一视觉信号，形状持续变形、漂浮并随时间/指针变化，把“发酵、菌丝、营养与生命力”转成可感知的品牌语言。
- 同一母题继续出现在产品图片边框、应用信息层、ESG 转场、生产闭环、统计背景和新闻装饰中，避免每个模块使用互不相关的科技特效。
- 可借鉴的是“从产品机理提炼一个可变视觉语法”，而不是复制液态渐变。视觉母题必须能解释技术或产品特性，并准备静态 SVG/图片终态、透明度和对比度规范，不能遮挡关键文字。

### 首页按认知问题分配滚动章节

- 桌面首页高度约 13187px，其中三个 `pin-spacer` 分别约 2400px、4500px 和 2900px，合计约占页面滚动长度的 74%。它们依次承担“这是什么”“能做什么”“为什么可持续”三个认知问题。
- 第一段将全屏液态场逐步收束为圆形微观世界，并转出“用微生物智慧重构蛋白质未来”；第二段在固定视口中顺序切换食品应用；第三段以森林航拍为固定背景，依次显示 ESG 价值、绿色生产闭环和过程节点。
- 复用时先制作动效分镜表，为每一段写清业务问题、起始状态、滚动中间状态、最终静态状态、可跳过路径和移动端替代。只有当一段滚动确实完成理解任务时才使用固定场景。

### 从核心原料建立“产品形态 + 应用”双路径

- 主导航的“产品与应用”继续拆分未冉蛋白、产品和应用。首页先展示鲜素块、湿基蛋白和干基蛋白，再进入饮料、休闲食品、大健康、预制菜等使用场景。
- 这种结构适合“核心技术只有一个，但交付形态和客户任务很多”的业务。食品研发人员可以从原料形态判断规格，品牌/市场人员可以从最终品类理解合作空间。
- 数据模型应维护 `platform/ingredient -> format -> property/specification -> application -> prototype/case -> evidence` 关系，让产品页、应用页和详情读取同一数据，不在轮播中分别硬编码。

### 用真实消费场景降低技术理解门槛

- 应用段使用饮料、烘焙零食、代餐和预制食品等生活场景照片，中央液态层写明应用名称、示例品类与价值方向，比只展示实验室、菌株或抽象分子更容易连接终端产品。
- 场景图片和核心原料视觉同时存在，使网站既保留消费品亲和力，也没有丢失生物制造身份。
- 食品科技站可采用“真实食物/消费状态 + 配方任务 + 技术证据”三层组合；生活图不能替代样品图、营养/功能指标、工艺适配和法规边界。

### ESG 从价值主张继续到过程图

- 首页和 ESG 页先给出生态生产、循环经济、可持续性、未来营养四个方向，再把糖类原料、运输、种子培养、发酵、分离、农产品种植和蛋白产品组成闭环。
- 这一顺序比直接显示一张复杂流程图更易理解：先建立四个判断维度，再展开具体过程关系，最后使用影响数字收束。
- 复用时要继续补充系统边界、输入输出、废弃物去向、对比基准、生命周期阶段和第三方验证；“循环”图形本身不能证明零废弃或减碳。

### 企业证据分散到不同决策阶段

- 产品页用认证矩阵建立食品安全与市场准入信号，公司页用 2023-2025 时间线、生产线和建设进展说明成长路径，新闻页继续提供大会、专利、认证和科普内容。
- 首页的高动效负责建立兴趣，内页负责承接产品、应用、企业和 ESG 证据，这是正确的职责分工方向。
- 证据仍应回流到产品/应用详情：认证适用于哪个公司、工厂、原料或产品，产能是设计、在建还是实际产量，都要在相关决策位置说明，不能只在企业介绍中集中展示。

### 移动端保持页面宽度但没有充分解除滚动接管

- 390x844 下首页、产品页、详情、公司和 ESG 页均满足文档 `scrollWidth=375px`，未出现根级横向滚动；首页 Hero 文字缩为约 42px/31.5px/19.25px，主要内容使用 15px 左右内边距。
- 移动菜单改为全屏侧滑层，展开后锁定背景滚动；产品、公司和 ESG 内页也没有根级横向溢出。
- 但移动首页仍有约 1644px、4220px 和 1688px 的三个固定滚动段，合计约占 10395px 页面长度的 73%；产品页和 ESG 页也分别保留约 1688px、2844px 的固定段。它完成了尺寸适配，却没有充分完成交互降级。

## 适用条件

- 客户处于食品科技、生物制造、合成生物、发酵原料或其他需要先解释新概念的行业，拥有一个核心技术平台/原料和多个交付形态或应用方向。
- 主要受众包含食品研发、配方、采购、品牌合作、产业伙伴与需要基础科普的公众，网站目标是建立品类认知、合作想象和技术信任，而不是快速比价下单。
- 客户能提供真实产品/样品、配方或应用原型、生产流程、研发/工厂、认证、时间线和经审核 ESG 数据，且能持续维护证据时效。
- 项目预算能够覆盖动效分镜、桌面/移动两套编排、静态回退、键盘与触摸、减少动效、性能预算和多页面回归，而不只是购买动画库拼接效果。
- 品牌视觉确实可以从产品机理中提炼一个长期使用的动态母题，并能在没有动画时保持识别度。

## 不应照搬

- **固定滚动占比过高：** 桌面和移动首页约四分之三的滚动距离处于三个 pinned 章节。视觉记忆强，但快速查找、回看、键盘导航和低性能设备的成本明显；移动端不应只等比例缩短桌面滚动距离。
- **动画依赖堆叠：** 首页 DOM 含 30 个脚本，并同时加载 jQuery、Swiper、Swiper Animate、WOW、Waypoints/CountUp、GSAP、ScrollTrigger、SplitType、SplitText、Lenis、SuperSlide、液态粒子、视差插件和 Anime.js 等。复用时先以能力矩阵去重，同一动画职责只保留一个主要实现。
- **通用脚本越界初始化：** 多页面审阅会话累计出现大量 `GSAP target ... not found`、`Element not found` 警告，并记录到 `gsap.js:1058` 的 `TypeError`；说明脚本在不相关页面仍查询并初始化不存在的模块。每页/组件应按根节点存在性和生命周期注册、销毁 ScrollTrigger，不让共享脚本扫描全站选择器。
- **Lenis 使用弃用参数：** 控制台重复提示 `smooth` 已弃用、应使用 `smoothWheel`。依赖版本、初始化参数和滚动库之间的控制权必须统一，交付前清理警告。
- **减少动效未确认：** 可读取样式表未发现 `prefers-reduced-motion` 规则，另有跨域样式表无法检查。我们的实现必须主动提供减少动效、低性能和脚本失败终态，不能因参考站未显示而跳过。
- **标题语义和页面语言错误：** 抽查页面唯一标题元素主要是社交分享组件的 H4，可见页面标题没有形成有效 `h1`-`h6` 大纲；中文首页的 `html lang` 为 `en`。每页应有唯一 H1、连续标题层级和正确语言标记。
- **移动菜单只有视觉状态：** 390px 菜单开关为普通 `div.sp_nav`，未见 `role`、`tabindex`、可访问名称或 `aria-expanded`；打开后焦点仍在 `body`。虽然背景滚动被锁定，仍需改为按钮并实现焦点进入、Esc、陷阱和恢复。
- **轮播控件语义不足：** 首页上一张/下一张使用带 `aria-label` 的 `div`，不等于可键盘操作的按钮；分页点约 14px，触控面积偏小。应使用原生按钮并扩展点击区域。
- **产品详情证据偏薄：** 抽查鲜素块详情的可读取正文主要是产品名和优质蛋白、高膳食纤维、零胆固醇、零添加剂四项卖点，未见完整营养表、成分/菌种边界、规格版本、储存/保质、加工适配、认证适用范围、技术资料或样品咨询路径。高动效首页不能替代 B2B 详情证据。
- **食品与 ESG 主张需要口径：** `零添加剂`、GRAS、产能、减碳、少养牛/鸡和植树换算等都是参考站点展示；复用前必须确认法规地区、主体/产品范围、计算边界、基准年、数据源和免责声明。
- **内容与链接 QA：** 公司页使用 `/compnay` 拼写路径，详情页邮箱链接出现 `matilto:`，若干触发器使用 `javascript:;`。即使为兼容保留历史 URL，也应建立规范 URL、重定向、真实 `mailto:` 和可分享交互状态。
- **方向感知导航可能失步：** 快速程序化上下滚动后，桌面导航在回到 `scrollY=0` 时仍保留 `active hide` 状态。滚动导航、返回顶部、锚点和浏览器恢复位置需要独立回归，不能只测试正常慢速滚轮。
- **视觉层级不能只靠超大文字：** 首页中英文标题和数据字号较大，适合品牌展示但不应成为食品科技站默认。长术语、多语言和移动端应先保证完整可读、换行与信息密度。

## 复用时的最小验收

- 制作“技术定义 -> 产品形态 -> 应用任务 -> 生产/ESG -> 企业证据 -> 合作 CTA”内容地图；每个动效章节只回答一个明确问题，并有直接链接或跳过路径。
- 为每个固定滚动章节记录触发区间、固定距离、进入/退出状态、最终静态帧、快速滚动、反向滚动、锚点直达和刷新恢复；任何状态下正文与 CTA 都不依赖动画播放完才可见。
- 1440px 下验证 Canvas 粒子、文字揭示、产品轮播、应用横移、ESG 过程图、计数和新闻轮播；390px 默认将长 pinned 章节改为自然单列、横滑或可点击步骤，确需保留时逐段证明其阅读收益。
- 开启 `prefers-reduced-motion: reduce` 后停止 Canvas 持续运动、DNA 循环、视差、自动轮播、计数和长距离固定滚动，直接显示各章最终状态；低性能/省流量状态提供同等静态回退。
- 产品、产品形态、规格、属性、应用、原型/案例、认证和资料来自统一关系模型；从任一应用可回到适用产品，从任一产品可查看应用、证据和咨询入口。
- 每个产品详情至少包含真实样品图、产品定义、规范化营养/技术指标、规格与包装、储存/保质、应用与加工边界、认证范围、版本化资料和申请样品/技术咨询 CTA；缺失项明确待补。
- ESG 数字记录数据源、基准、单位、系统边界、换算公式、审核角色和更新时间；计数动画的最终数值与正文/后台一致，未经核实的数据不发布。
- 页面级动效只在对应根节点存在时初始化，路由离开时销毁监听器、Swiper 和 ScrollTrigger；控制台不得出现缺失目标、重复注册、弃用参数或未捕获异常。
- 中文页使用 `lang=zh-CN`，每页有唯一文本 H1 和连续标题层级；Canvas、流程图、SVG、轮播和数据图提供文本等价物、替代文本和可访问名称。
- 移动菜单、下拉、轮播、标签、固定联系方式与返回顶部使用语义控件，支持 Tab/Shift+Tab/Enter/Space/Esc、焦点管理、背景锁定和至少约 44x44 CSS px 触控区域。
- 检查 1920px、1440px、1024px、768px 和 390px 的根级横向溢出、固定元素遮挡、长文本换行、图片裁切和滑动手势；脚本/图片/字体失败时页面仍是可读的普通文档流。
- 对首页和每个实际加载不同动效组合的代表性内页分别检查控制台、帧率、长任务、LCP、CLS、内存、页面切后台和返回恢复；不要用首页通过推断所有内页通过。

| 动效依赖 | GSAP/ScrollTrigger、SplitType/SplitText、Lenis、Anime、Swiper、WOW、液态粒子和视差脚本 | 仅作参考 | 无 | 不复制；依赖职责重叠并出现跨页缺失目标、弃用参数和异常，应按项目能力矩阵重选 |
