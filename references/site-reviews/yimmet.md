# YIMMET 宜美照明场景化产品与案例站参考拆解

## 审阅范围

- 参考站点：[YIMMET / 江苏宜美照明科技股份有限公司](https://www.yimmet.cn/)
- 审阅日期：2026-08-21
- 实际检查页面：[首页](https://www.yimmet.cn/)、[产品中心](https://www.yimmet.cn/product)、[窄边框筒灯产品详情](https://www.yimmet.cn/downlight/806)、[品牌案例](https://www.yimmet.cn/case)
- 实际检查视口：桌面端 1440x900（首页）及约 1684x887（代表性内页补充），移动端 390x844
- 分类标签：室内 LED 照明、商业照明、教育照明、家用照明、节能照明、制造商品牌站、产品目录、电商导流、工程案例、场景摄影、黄灰现代工业、动效叙事、中高内容密度
- 未验证项：未检查英文站、全部产品和案例、新闻详情、站内搜索与组合筛选实际提交、功率滑块边界、外部商城与客服会话、联系或询价提交、真实电话和邮箱可达性、真实移动设备、弱网、屏幕阅读器及完整键盘路径；移动端使用 390x844 可控视口完成 DOM、布局与交互检查，但浏览器截图能力不可用，因此移动端视觉判断以计算布局和可见页面状态为准。
- 可读取的 8 个样式表未发现 `prefers-reduced-motion` 规则，另有 9 个跨域样式表无法读取，因此不能确认减少动效支持；抽查首页及三个代表性内页的桌面控制台、移动端审阅会话均未记录 warning 或 error。
- 参考站点自述的成立时间、规模、产能、销售、客户、产品性能、节能效果、认证和案例关系均未做独立事实核验；本文只提炼结构和验收方法，不复制品牌素材、图片、文案、客户名称、型号参数或能力数字。

## 核心判断

该站最值得借鉴的不是某一种轮播或黄色点缀，而是把照明产品的四段决策证据串在了一起：首页先用办公室、教室、商业和家居等真实空间说明“光最终作用在哪里”，再把健康、可靠、节能、光学和智能能力转成可理解的产品价值；产品中心负责按产品库、产品类型、功率和特色功能缩小范围；详情页继续提供场景、性能点、参数和购买入口；案例页则用项目背景与现场图片补上落地证明。它适合同时面向工程采购、设计/经销合作方和部分终端消费者，且拥有较完整场景图、产品图、参数与项目资产的照明或建筑设备制造商。

## 值得借鉴

### 先展示光的使用结果，再展示灯具本体

- 首页首屏使用办公室、教室等真实空间作为轮播主体，产品不是孤立悬浮在科技背景上。对照明业务而言，用户先看到照度氛围、空间类型和安装效果，再接触灯具名称，更容易理解产品价值。
- 首屏后以“新商照”和品牌主张承接，再进入办公、停车场、教室、家居等场景卡片，随后才展开产品结构、技术能力和新闻。整体顺序接近“结果场景 -> 品牌方法 -> 产品能力 -> 持续证明”，比先铺企业介绍更符合首次访问者的认知路径。
- 复用时应为每张场景图绑定空间类型、目标问题、使用产品、关键指标和相关案例。场景图不能只是氛围素材，必须能继续到产品或方案证据。

### 目录同时支持业务场景与技术属性选型

- 主导航先用商用、节能、教育、家用四个产品库承接不同业务场景，产品中心再提供平板灯、条形灯、筒射灯、吸顶灯、轨道灯等产品类型，兼顾“我要做教室照明”和“我要找筒灯”两种入口。
- 筛选继续加入功率范围，以及新商照、超节能、教育级灯具、全光谱、可调功率、可调色温、感应、智能控制、模块化、金属壳体、应急防火等功能标签。分类与功能筛选链接使用查询参数，具备分享和返回结果状态的基础。
- 390px 下产品库保持四列入口，类型与功能按三列短选项排列，产品卡切换为两列，根级没有横向溢出。它证明高信息量筛选不必在手机上全部隐藏，但搜索区按钮换到下一行且对齐较弱，复用时应把筛选做成折叠面板、底部抽屉或紧凑的两段布局。
- 目录数据应统一建模为 `business_library/use_case -> product_type -> power/spec -> feature -> product -> model`，并让 URL、卡片标签、详情参数和相关产品从同一数据源生成。

### 产品详情兼顾品牌销售与工程选型

- 抽查详情首屏用大幅真实产品图、名称、简短价值主张和购买 CTA 建立商品感；桌面端另有“概览 / 参数 / 购买”产品级导航，不让用户在长页面中失去当前位置。
- 正文把高显色、防眩、无可视频闪、无蓝光危害等性能点，与客厅、过道等应用场景、产品结构图和规格表串联。对非专业消费者先讲可理解的使用收益，对工程用户保留功率、电压/频率、色温、角度、显色指数等参数。
- 购买入口连接外部商城，使企业官网承担品牌解释、技术教育和商品导流，而不必复制完整交易系统。复用时应明确区分“获取方案/询价”和“立即购买”：工程项目需要工况表、配光资料和咨询路径，标准消费品才适合直接跳商城。
- 390px 下参数表位于约 348px 宽的横向滚动容器，宽表没有撑开根页面；桌面产品级导航在移动端隐藏，改用自然文档流。此策略可用，但还应提供横滑提示、冻结首列、规格下载或型号选择器。

### 案例用项目背景和现场图共同证明

- 案例页按全部、商用照明、教育照明和超节能照明筛选，而不是把所有项目混在一条品牌瀑布流中。
- 单个项目模块同时包含项目名称、背景说明和多张现场图轮播。文字回答“这是怎样的空间”，图片回答“灯光落地后怎样”，比只有客户 Logo 或一张封面更接近工程采购需要的证据。
- 桌面端用大面积交错图文卡建立节奏，390px 下分类入口仍保持一行，项目标题与正文改为单列，根级无横向溢出。复用时还应补充项目目标、采用产品、设计/施工范围、前后对比、验收口径、时间与素材授权状态。

### 动效围绕空间、产品和技术状态分层

- 首页使用 Swiper 淡入首屏轮播、WOW/fadeInUp 进入效果、技术结构的循环轨迹动画，以及新闻和产品卡片轮播；产品详情则通过场景轮播和滚动章节控制信息密度。动效主要服务场景切换、产品拆解和内容分组，而不是在每个区块叠加无意义装饰。
- 页面同时加载 Swiper、WOW、GSAP、ScrollTrigger、SplitText、ScrollSmoother、Waypoints、CountUp 和 SuperSlide 等多套能力，说明参考价值在“动效目的分层”，不在依赖组合。复用时应先写明每段动效的触发器、状态变化、信息目的、最终静态帧和减少动效方案，再选择最少的实现依赖。
- 首屏、产品场景和案例轮播都提供分页状态；桌面右侧联系/客服浮层克制地停在边缘，移动端则隐藏该浮层，只保留固定顶部栏，避免多个固定入口抢占窄屏。

### 移动端使用独立媒体资产而非直接裁桌面图

- 390px 首页可识别出 11 张可见的移动专用图片，桌面版本在该断点隐藏；首屏高度约 667px，顶部栏约 60px，品牌和空间仍是第一屏主要信号。
- 首页从桌面较长的展示节奏压缩为约 2917px 的移动自然流；产品目录、详情和案例页也保持单向滚动，没有把桌面全宽布局整体缩小。
- 产品目录两列卡片、案例单列项目、详情横滚参数表分别对应不同信息关系，说明响应式不是统一“全部改一列”。复用时应按卡片比较、叙事阅读、数据表三种任务分别设计断点。

### 联系、内容更新与页脚形成持续转化入口

- 桌面固定联系/客服入口、导航电话、页脚邮箱和电话、产品详情购买 CTA 分别覆盖即时沟通、基础联系和交易导流；页脚的 `mailto:` 与 `tel:` 链接保留了基本可操作性。
- 首页新闻把技术解释、产品发布、展会和企业动态放在产品能力之后，可承担搜索入口和品牌活跃度证明。内容卡片包含日期、标题和独立详情 URL，适合连接到相关产品或场景方案。
- 复用时应限制固定入口数量，明确不同 CTA 的受众和下一步；新闻需要作者/审核、来源、更新时间、相关产品与退役规则，不能只用于关键词堆叠。

## 适用条件

- 客户销售照明、电气、建筑设备、智能家居组件或其他“安装后效果比孤立产品更重要”的实体产品。
- 同时存在工程采购、设计/经销合作方和终端消费者，访客可能按空间场景、产品类型、技术属性或具体型号进入。
- 产品数量和属性足以支撑筛选，且客户能维护产品库、类型、功率/规格、功能标签、型号和商城/询价关系。
- 客户拥有经过授权的真实空间、产品细节、结构拆解、安装效果和项目案例资产；缺少真实资产时，不应以泛化效果图伪装落地能力。
- 品牌目标同时包含形象展示、选型教育、销售线索与电商导流；如果只有少量定制项目、没有标准产品或不做线上销售，应简化目录和购买路径。

## 不应照搬

- **页面主题语义几乎缺失：** 抽查四个页面都没有有效文本 H1，首页除分享浮层的 H4 外没有正式标题；页面没有 `main` 或 `nav` 元素，中文站的 `html lang` 为 `en`。每页应有唯一文本 H1、连续 H2/H3、`main`/`nav` 地标和正确的 `zh-CN` 语言声明。
- **移动菜单不是可访问控件：** 菜单开关 `div.sp_nav` 和关闭 `div.close_nav` 都没有按钮角色、键盘焦点、可访问名称、`aria-expanded` 或 `aria-controls`；打开后焦点仍在 `body`，按 Esc 不会关闭。应使用原生按钮，管理打开/关闭焦点、焦点陷阱、Esc、状态宣告和触发器焦点恢复。
- **依赖和资源规模偏重：** 首页实测约 145 张图片、25 个脚本和 17 份样式，图片没有使用原生 `loading="lazy"`；`ScrollSmoother.min.js` 还被重复加载。应按页面拆包、首屏优先、下方媒体懒加载，并避免轮播副本重复下载同一资源。
- **减少动效支持没有证据：** 8 个可读取样式表未发现 `prefers-reduced-motion`，9 个跨域样式表无法确认。轮播自动播放、循环轨迹、平滑滚动和进入动画在减少动效时应停止，并直接显示稳定最终帧。
- **轮播副本造成语义和布局噪声：** 首页可见 220 个链接和大量重复新闻/产品内容；桌面根 `scrollWidth` 一度约 4533px，而可视宽约 1425px，只靠根级 `overflow-x: hidden` 遮住离屏轮播副本。根级隐藏不能替代正确的轮播容器裁剪，复制项还应从可访问树移除并避免重复焦点。
- **核心内容依赖进入动画显现：** 桌面整页静态抓取中多个文字区和卡片保持空白初态，滚动后才进入。JS 失败、打印、静态导出或减少动效模式下，核心内容必须默认可见；动画只从可读终态向增强状态过渡。
- **图片替代文本治理不足：** 首页 145 张图片中 70 张 `alt` 为空、11 张缺少 `alt`；其中虽包含装饰图和轮播副本，但产品、场景、案例和信息图必须提供准确语义，装饰图才使用空替代文本。
- **筛选控件语义不足：** 产品页存在多个表单与输入，但抽查没有 `label`；视觉上类似复选框的分类链接实际是导航链接，功率范围滑块和搜索输入需要明确名称、当前值、键盘操作和结果数量宣告。
- **案例首屏对比度不稳定：** 案例页白色大标题叠在很浅的横幅图上，抽查视口下可读性较弱。文字叠图必须对每张资产做最差帧对比度验收，必要时增加局部遮罩或改用独立标题区。
- **SEO 标题过度堆词：** 首页标题连续罗列多类产品和关键词，虽然覆盖业务词，但削弱品牌识别和搜索结果可读性。标题应围绕品牌、核心品类与差异化价值组织，长尾需求交给分类页和内容页。
- **外链安全细节不足：** 抽查页面存在多个 `target="_blank"` 外链未带 `rel="noopener"`。商城、社交和其他第三方入口应补齐安全属性、外部站提示与失效监测。
- **站点主张不能直接继承：** 参考站的产品性能、健康效果、节能数据、企业规模和项目客户均只代表站点展示。新项目必须取得原始报告、适用条件、授权和审核结论后再发布。

## 复用时的最小验收

- 首页首屏使用经过授权的真实产品或实际空间，首个视口能识别品牌、空间/产品类别、核心价值和一个主要 CTA；场景入口能继续到相关产品、方案或案例。
- 建立 `use_case/business_library -> product_type -> spec -> feature -> product -> model -> evidence` 数据模型；产品分类、筛选 URL、卡片标签、详情参数和相关案例从同一数据源生成。
- 产品目录至少提供适合规模的分类、搜索和筛选，状态写入 URL并支持刷新、返回和分享；有结果数量、无结果、清空条件和错误状态，键盘与屏幕阅读器可操作。
- 产品详情同时提供真实产品图、适用场景、可核实性能点、规格单位与测试条件、资料版本、相关产品，以及面向工程项目的询价/选型入口；标准商品购买入口与工程咨询入口不混用。
- 每个案例至少包含项目背景、目标/问题、服务范围、采用产品、真实现场资产和一项经过确认的结果或验收证据；客户关系、图片、Logo 和数字有授权、来源、日期与适用范围。
- 动效实现收敛为满足需求的最少依赖；没有重复脚本和跨页面无目标初始化。自动轮播可暂停，分页和前后控制有名称，复制项不可聚焦；`prefers-reduced-motion` 下停止自动运动、取消滚动接管并显示最终内容。
- 1440px 下轮播和滚动模块不扩大根页面宽度；390px 下根级 `scrollWidth <= clientWidth`，使用移动专用构图或受控裁切，产品卡、筛选、案例和固定入口互不遮挡。
- 移动宽表放入可感知的横向滚动容器，提供边缘渐隐、滑动提示、冻结首列或型号切换；触摸、键盘和屏幕阅读器能理解表头与数据关系。
- 每页只有一个描述主题的文本 H1，使用正确 `lang`、`main`/`nav` 地标和连续标题层级；移动菜单使用原生按钮，支持 Tab、Enter/Space、Esc、焦点陷阱与焦点恢复。
- 首屏外图片与视频按需懒加载并预留尺寸，轮播副本不放大请求数量；JS 失败、弱网、打印和减少动效模式下仍可读取核心文案、产品名称、参数与 CTA。
- 联系电话、邮箱、商城、客服和社交外链逐项验证；新标签外链使用 `rel="noopener noreferrer"`，第三方失效时有回退。交付前检查控制台无可修复异常、图片无破损、主要内容无空白初态。
